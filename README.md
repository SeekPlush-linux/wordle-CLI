# wordle-CLI &middot; [![GitHub Release](https://img.shields.io/github/v/release/SeekPlush-linux/wordle-CLI?logo=github&label=Release&labelColor=%2307a007&color=gray)](https://github.com/SeekPlush-linux/wordle-CLI/releases)

Play Wordle straight from your terminal.

## Prerequisites

Ensure you have the following programs installed:

- Python (`py` for Windows, `python3` for Linux/MacOS)

## Installation

1. Go to the [Releases](https://github.com/SeekPlush-linux/wordle-CLI/releases) page
   and download the source code from the latest release.

3. Extract the archive file and open a terminal in the extracted folder.

4. In the terminal, install the required Python packages:
   ```
   py -m pip install -r requirements.txt
   ```

5. Done! To start playing, simply launch the main Python script:
   ```
   py wordle-CLI.py
   ```
